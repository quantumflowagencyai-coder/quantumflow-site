# quantumflow-site

Kod strony https://quantumflow.agency (QuantumFlow AI Agency), hostowanej na Vercel (projekt `quantumflow-agency`).

- Vercel buduje stronę poleceniem `npm run build` (`build.js`) do katalogu `public/`.
- Grafiki HD (`img/`) build pobiera z tego repozytorium z przypiętego commita (`_src/hd.json`) i sprawdza ich sumy sha1.
